# Códigos retirada/entrega — Plano 3: App do motorista

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use `- [ ]`.

**Goal:** Quando a empresa exige, o motorista digita o código na coleta (start-attendance) e na entrega (conclusão); com "não tenho o código → informar motivo" quando a empresa permite bypass. O app lê os flags `service.confirmationCode` (backend já expõe) e chama os endpoints que já validam.

**Tech:** React Native/Expo. jest-expo, react-test-renderer, **sem RTL** → lógica pura testável + tsc + manual (device). `git add <arquivos>` específicos, nunca `-A`.

## Global Constraints
- Vale para o per-serviço `serviceType` (DELIVERY/PICKUP/TRANSFER/SERVICE) — NÃO para malha (`routing.legType`). O `TransferLegExecution` (malha) não chama start-attendance/completion; não tocar.
- O código NUNCA vem do backend para o app (só os flags). O motorista digita o do cliente.
- Bypass só quando `service.confirmationCode.allowCodeBypass`. Motivo obrigatório. Reason codes do backend (CODE_BYPASS): `CLIENTE_SEM_CODIGO`, `CLIENTE_AUSENTE`, `OUTRO` (OUTRO exige texto).
